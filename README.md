## Tools
Python, pandas, NumPy, scikit-learn, XGBoost, Matplotlib and Seaborn.

## Opening the work
Open each notebook in Jupyter or Google Colab and install requirements.txt. Supply the datasets referenced by the notebook: diabetes.csv, Data.xlsx, Titanic-Dataset.csv or Titanic_Cleaned_Dataset.csv. The original /content paths are for Colab and may need to be changed locally.

The accompanying task briefs are included. Notebook outputs have been cleared. Source datasets remain in Drive. Source code is preserved and has not been rerun during publishing.
